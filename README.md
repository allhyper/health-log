# 症状記録 PWA

自分専用の「症状エピソード」記録Webアプリです。体重・歩数などの一般的な健康管理ではなく、体調不良の開始から終了までを1つのエピソードとして記録します。

## MVPでできること

- 新しい症状の登録
- 部位プリセット（お腹、頭、顔、目、鼻、口、耳、喉、首、肩、腰、ひじ、手、股関節、ひざ、足、皮膚、その他）＋自由入力
- 継続中症状のカード表示
- 「昨日と同じ」1タップ記録
- 「今日も全部昨日と同じ」一括記録
- 改善 / 悪化 / 治った
- きっかけ・心当たり
- 市販薬 / 処方薬 / 病院受診 / その他の対応記録
- 途中メモ
- 症状本体と途中記録の編集、確認付きの個別削除・症状全体の削除
- 下痢のみ回数・腹痛の任意記録
- 履歴、症状・部位・期間での絞り込み
- 症状ごとの簡易集計
- 終了済み症状の再開
- IndexedDB保存
- JSONバックアップ / 復元
- CSV出力
- PWA / オフライン基本動作

外部DB、ログイン、解析、広告、トラッキングは使用していません。

## 記録後の編集・削除

現在の症状の **詳細を見る**、または **履歴** の症状を開いて操作します。終了済みの症状も編集できます。

- **症状を編集**: 部位、左右、症状、開始時の程度、開始日、終了日（終了済みの場合）、きっかけ・心当たりを変更します。
- 各記録の **編集 / 削除**: 日々の変化・程度・下痢の補足、薬や病院の対応、途中メモを1件ずつ変更・削除できます。日付も変更できます。
- **この症状をすべて削除**: 確認後、その症状と関連する途中記録だけを削除します。他の症状は残ります。
- 削除は元に戻せません。各削除画面で対象を確認でき、キャンセルできます。

開始の記録を編集すると症状本体の開始日・開始時の程度も更新されます。症状本体の日付を変えた場合も、存在する開始・終了の記録の日付を合わせて更新します。日々の変化は1日1件で、開始日・終了日の範囲外や日付の重複は保存できません。

終了日の「治った」を別の変化へ変更、または削除すると、症状は継続中に戻ります。再開済みの症状に残る過去の「治った」を編集しても、再び終了にはなりません。開始の記録だけを削除した場合は、症状本体の開始日・開始時の程度は残ります。メモ登録時に心当たりへ追記した内容は、症状本体の **きっかけ・心当たり** から編集します。

保存形式とIndexedDBのバージョンは従来のままです。既存データ・JSONバックアップをそのまま利用できます。PWAのキャッシュは更新されますが、記録データは消去しません。公開後に旧画面が出る場合は、オンラインで開いてからアプリを閉じ、もう一度開いてください。

## ローカルでの確認

配信時にビルドやnpmパッケージは不要です。テスト・ローカル確認のみNode.jsを使います。

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
npm start
```

`npm start` 後は `http://127.0.0.1:4173/health-log/` で確認できます。ブラウザー試験はPC幅とスマートフォン幅で動作します。インストール済みEdgeを使う場合は、PowerShellで `$env:PLAYWRIGHT_CHANNEL='msedge'` を設定してから実行します。

## データ構造

IndexedDBの `episodes` ストアに、1症状=1エピソードで保存します。

主な項目:

- `id`
- `status` (`active` / `closed`)
- `body`, `side`, `symptom`
- `startDate`, `endDate`
- `initialSeverity`
- `trigger`
- `daily[]` : 日々の変化
- `responses[]` : 薬・病院等
- `notes[]` : 途中メモ

## GitHub Pagesで公開

1. このリポジトリをGitHubにpushします。
2. GitHubのリポジトリ画面で **Settings → Pages** を開きます。
3. **Build and deployment** の Source を **Deploy from a branch** にします。
4. Branch を `main`、Folder を `/(root)` にして保存します。
5. 表示されたGitHub Pages URLをスマートフォンで開きます。

すべて相対パスで作っているため、`https://ユーザー名.github.io/リポジトリ名/` 配下でも動作します。

## バックアップ

アプリ下部の **データ** 画面から操作します。

- **JSONを書き出す**: 全データを完全バックアップ
- **JSONを読み込む**: バックアップから復元（現在データを置換）
- **CSVを書き出す**: 一覧確認用

端末変更やブラウザデータ削除に備え、JSONを定期保存してください。

## 注意

- データはブラウザのIndexedDBに保存されます。
- ブラウザのサイトデータを削除すると消えるため、JSONバックアップが必要です。
- 医療判断・診断を行うアプリではありません。
