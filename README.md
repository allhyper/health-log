# 症状記録 PWA

自分専用の「症状エピソード」記録Webアプリです。体重・歩数などの一般的な健康管理ではなく、体調不良の開始から終了までを1つのエピソードとして記録します。

## MVPでできること

- 新しい症状の登録
- 部位プリセット（お腹、頭、顔、目、鼻、口、耳、喉、首、肩、腰、ひじ、手、股関節、ひざ、足、皮膚、その他）＋自由入力
- 継続中症状のカード表示
- 「昨日と同じ」1タップ記録
- 「今日も全部昨日と同じ」一括記録
- 改善 / 悪化 / 治った
- きっかけ・心当たり
- 市販薬 / 処方薬 / 病院受診 / その他の対応記録
- 途中メモ
- 下痢のみ回数・腹痛の任意記録
- 履歴、症状・部位・期間での絞り込み
- 症状ごとの簡易集計
- 終了済み症状の再開
- IndexedDB保存
- JSONバックアップ / 復元
- CSV出力
- PWA / オフライン基本動作

外部DB、ログイン、解析、広告、トラッキングは使用していません。

## データ構造

IndexedDBの `episodes` ストアに、1症状=1エピソードで保存します。

主な項目:

- `id`
- `status` (`active` / `closed`)
- `body`, `side`, `symptom`
- `startDate`, `endDate`
- `initialSeverity`
- `trigger`
- `daily[]` : 日々の変化
- `responses[]` : 薬・病院等
- `notes[]` : 途中メモ

## GitHub Pagesで公開

1. このリポジトリをGitHubにpushします。
2. GitHubのリポジトリ画面で **Settings → Pages** を開きます。
3. **Build and deployment** の Source を **Deploy from a branch** にします。
4. Branch を `main`、Folder を `/(root)` にして保存します。
5. 表示されたGitHub Pages URLをスマートフォンで開きます。

すべて相対パスで作っているため、`https://ユーザー名.github.io/リポジトリ名/` 配下でも動作します。

## スマホのホーム画面へ追加

### iPhone / Safari
1. GitHub PagesのURLをSafariで開く
2. 共有ボタン
3. **ホーム画面に追加**
4. **追加**

### Android / Chrome
1. GitHub PagesのURLをChromeで開く
2. メニュー
3. **ホーム画面に追加** または **アプリをインストール**

## バックアップ

アプリ下部の **データ** 画面から操作します。

- **JSONを書き出す**: 全データを完全バックアップ
- **JSONを読み込む**: バックアップから復元（現在データを置換）
- **CSVを書き出す**: 一覧確認用

端末変更やブラウザデータ削除に備え、JSONを定期保存してください。

## 注意

- データはブラウザのIndexedDBに保存されます。
- ブラウザのサイトデータを削除すると消えるため、JSONバックアップが必要です。
- 医療判断・診断を行うアプリではありません。
